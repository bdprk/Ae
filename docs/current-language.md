# AE 当前原型语义（未稳定）

本文只描述已经实现的子集，不代表未来语言最终设计。

## 词法与结构

源文件采用 UTF-8。标识符由 ASCII 字母或下划线开头，后续可包含数字；关键字保留（`fn let var print if else while for in return break continue assert true false use`）。文件顶部可写 `use "相对路径.ae";` 引入其他文件：按导入文件所在目录解析、深度优先加载、环导入报错；函数名跨文件唯一，`main` 全程序唯一（库文件无需 main）。空白分隔词元，`//` 注释延伸至行尾。字符串字面量用双引号，支持 `\n`、`\t`、`\\`、`\"` 转义，不允许原始换行或 NUL。程序有且仅有一个 `fn main() { ... }`，也可定义其他函数。语句以分号结束。

## 值与计算

标量类型为有符号 64 位整数 `i64` 与布尔 `bool`；另有拥有型 `string` 与固定长度 `i64` 数组。整数字面量目前仅支持 0 至 9223372036854775807；一元负号与减法可产生负数。支持 `+ - * / %`，乘除模高于加减，同优先级左结合，一元 `-` 和 `!` 比所有二元运算结合更紧，操作数从左到右求值。除法与求余向零截断，余数符号同被除数。溢出、除零使程序非零退出并在标准错误输出运算符的行列位置；开发与优化构建均不关闭这些检查。

比较 `== != < <= > >=` 作用于两个 `i64`；`==` 与 `!=` 也可比较两个 `string`（按内容）；产生 `bool`；`&&` 与 `||` 短路求值（右操作数仅在左操作数不能决定结果时求值），`!` 取反布尔。比较不可直接链接（`a < b < c` 因类型错误被拒绝）。

`let x = 表达式;` 声明不可变变量；`var x = 表达式;` 声明可变变量。声明前不能使用变量，不能重复声明；赋值要求类型一致。花括号引入词法作用域，内层可读符合可变性规则的外层变量；内层变量离开块后不可见，不能遮蔽当前可见的名称。`print(x);` 以十进制（整数）、`true`/`false`（布尔）或字符串内容加换行写入标准输出；`print("文本");` 直接输出字面量；输出错误使程序非零退出。`assert(条件);` 在条件为假时以非零状态报告断言行列位置。

## 拥有型字符串与移动语义

`string` 值拥有堆上的字节缓冲。初始化、按值传参、赋值与 `return` **移动**所有权；移动后原变量在编译期不可再使用（分支内移动后，分支合并处保守视为已移动）。对已移动变量赋值是合法的重新初始化；同一语句内右侧不能移动赋值目标自己。`+` 连接两个字符串并消耗两个操作数；`print` 与 `len` 借用不消耗。`len(s)` 返回字符串的 UTF-8 字节数。

释放在编译期插入：块结束、提前返回、`break`/`continue`（仅循环体内部声明的字符串）、函数返回路径全部覆盖；释放操作幂等（释放后指针置空），即使分析器与生成代码出现分歧也不会双重释放或使用已释放内存——每次读取字符串变量前有运行时空检查作为最后一道防线。内存分配失败使程序报告位置后非零退出。循环体内部的"先使用后移动"在循环首次迭代时不被编译期拒绝，由运行时检查捕获。

## 控制流程

`if 条件 { ... } else { ... }`：条件必须是 `bool` 表达式；支持 `else if` 链，末尾 `else` 可省略。`while 条件 { ... }` 每次循环重新计算条件。`for i in 开始..结束 { ... }` 迭代半开区间：界只求值一次且自左向右，`i` 是循环作用域内的不可变 `i64`，隐藏的自增是受检算术（到达 `i64` 最大值会安全失败）。`for x in 向量变量 { ... }` 按值迭代元素：`x` 是不可变 `i64` 拷贝，长度捕获一次；循环体内移动该向量在编译期拒绝，原地修改（`push`/`pop`/索引写）保持合法且受边界检查保护。`break` 立即退出最内层循环；`continue` 跳过剩余主体——在 `for` 中仍执行自增。`break`/`continue` 仅允许出现在循环内。

## 动态向量

`var v = vec[1, 2];` 创建拥有型可增长向量（`vec[]` 为空向量）。`push(v, x);` 与 `pop(v);` 是语句：要求可变局部变量、原地修改、不转移所有权；空向量 `pop` 报错。`v[i]` 读、`v[i] = x;` 写都按当前长度做边界检查（写入先检查下标再计算右侧）。`len(v)` 是运行时长度。向量与字符串一样拥有堆资源：赋值、按值传参、`return` 移动所有权；移动后使用编译期拒绝并有运行时空检查兜底；作用域退出与跳转路径幂等释放。`&vec` 参数是只读借用：可 `len`、可索引、可转借，不可写入、push/pop、解移动或越过被借值存活；调用点用 `f(&v)` 传入。向量元素是 `i64`；内置名 `vec push pop len read_file write_file bytes` 为保留名。

## 文件与字符串工具

`read_file(path) -> string` 读取整个文件为拥有字符串；`write_file(path, content) -> i64` 写入并返回字节数；两者借用参数，路径为 UTF-8（Windows 经 UTF-16 宽字符 API，非 ASCII 路径可用），失败以行列位置报告运行时错误。`bytes(s) -> vec` 把字符串按字节转为向量，用于字节级处理。`contains(s, sub) -> bool` 子串搜索（平台优化实现，借用两参数，空子串为真）；`slice(s, start, end) -> string` 返回拥有副本，越界以位置报告。字符串现在携带长度（`len`/`slice` 为 O(1)），缓冲区仍以 NUL 结尾供 C 互操作；`len`/`bytes` 按长度精确计数（含嵌入 NUL）。`read_file`/`write_file`/`bytes`/`contains`/`slice` 为保留名。

## 固定长度数组

`let a = [1, 2];` 声明不可变数组，`var a = [1, 2];` 声明可变数组。数组元素是整数表达式，自左向右求值；数组长度为 1 至 4096，只允许声明时使用数组字面量，不支持数组整体赋值、按值传参、返回或嵌套数组。`a[i]` 读取，`a[i] = value;` 需要可变数组。下标须为整数，负数或大于等于长度时程序报告下标位置并以非零状态退出；写入先计算并检查下标，再计算右侧。`len(a)` 是编译期常量（要求裸数组变量）。优化构建保持相同检查。

## 函数

`fn add(a: i64, b: i64) -> i64 { return a + b; }` 定义函数；返回类型可为 `i64`、`bool`、`string` 或 `vec`；参数类型可为 `i64`、`bool`、`string`（按值，移动）、`vec`（按值，移动）、`&vec`（只读借用）或 `&[i64; N]`（只读借用数组），最多 64 个。实参从左到右求值；字符串实参移动所有权。函数可以在调用点之前或之后定义，支持自递归和相互递归。所有路径必须明确返回值；编译器目前保守地只认可直接 `return` 或 `if`/`else` 两个分支均返回。`main` 不接受参数或 `return`。`len` 是内置函数，不能被重新定义。递归深度受系统栈限制。

## 只读数组参数

函数参数可写为 `a: &[i64; 3]`，调用时用 `f(&values)` 显式传入长度匹配的局部数组或只读数组参数。借用只在调用期间存在，可转借给其他函数；被调用函数不能写入、保存或返回借用。它是一种受限的只读参数，不是完整的借用检查或所有权系统。下标仍执行边界检查。

## 工具链

`ae check|emit-c|run|build|cache|version`。`build` 与 `run` 的产物基于内容寻址缓存：键覆盖生成的 C、优化模式、C 编译器标识、编译器版本与目标平台，相同输入直接复用可执行文件而不重新调用 C 编译器；缓存命中与全量构建语义一致。`AE_CACHE` 覆盖缓存位置，`cache dir|clear|stats` 查看与清理。`AE_CC` 指定 C 编译器；默认开发模式 `-O0`，`--release` 使用 `-O2`；两种模式保持相同语言语义与检查。`AE_TIMINGS=1` 输出阶段耗时与缓存命中情况。

## 字符串向量

`split(s, sep) -> vec[string]` 按分隔符切分（保留空段，Python 语义；空分隔符为运行时错误）；`join(parts, sep) -> string` 以分隔符连接（借用向量，总长先溢出检查）；`args() -> vec[string]` 返回程序参数（含 argv[0]；Windows 的 argv 为 ANSI 编码，如实标注）。`vec[string]` 是拥有型容器：赋值/传参/返回移动；`push` 移入字符串，`pop` 释放并移除末元素；`v[i]` 读与 `v[i] = s;` 写按当前长度做边界检查（写入先检查下标、释放旧元素、再移入新值）。**元素是只读借用**：不能把元素移出向量（拼接或赋给新变量被拒绝）；`len(v)` 为 O(1)。`split`/`args`/`join`/`lines`/`count_lines_with` 为保留名。`lines(s) -> vec[string]` 按换行切分：尾部换行不产生末尾空行，内部空行保留，空输入为零行（换行扫描为运行时字长优化实现）。 `count_lines_with(text, pattern) -> i64` 统计包含模式的行数：单遍零分配的融合实现，空文本为零、空模式匹配每一行。

## 借用字符串视图

`slice_view(s, start, end) -> string view` 创建零拷贝借用视图：基必须是**裸字符串变量**，创建后该变量在视图存活期（当前作用域）内不可移动、不可重新赋值（借用跟踪器拒绝）。视图是非拥有类型：赋值/传参即复制借用，永不释放。视图支持 `len`（O(1)）、`contains`、`==`/`!=`（按内容）、`print`、`bytes`、`slice`（得到拥有副本）、`slice_view`（再借用）；**不支持 `+` 拼接**（用 `join` 或 `slice` 取副本），也不可作为函数返回类型（无跨函数生命周期跟踪）。越界视图以位置报告运行时错误。`for x in vec[string]` 按借用视图迭代元素（不可移出元素，容器在循环内不可修改/移动）。

## 结构体

`struct Point { x: i64, y: i64 }` 定义命名字段序列；字段类型可为任意已注册类型（标量、string、vec、其他结构体）。自身引用在构造上即不可能（结构体名在其体内尚未注册），因此不存在无限大小布局。构造 `Point{x: 1, y: 2}`：字段可按任意顺序书写但各恰好一次，缺失/重复/未知字段被拒绝；字段表达式按声明序求值。后缀 `p.x` 读取：标量字段立即拷贝（后续释放不影响副本），拥有字段（string/vec/结构体）是**只读借用**——永远不能把字段移出结构体。`p.x = 值;` 字段赋值要求可变变量，覆盖前先释放旧拥有值。整体赋值 `p = 表达式;` 按移动语义：旧值先释放。结构体拥有其全部字段：赋值/传参/返回移动整个结构体，作用域退出、提前返回与跳转路径按类型生成的释放例程清理，绝不泄漏或双重释放。移动后使用由编译期移动集合拒绝（结构体无运行时哨兵，编译期检查是其防护，文档如实标注）。结构体名不能用作变量名；内置保留名同样不可作结构体/字段名外的顶层冲突。

## 当前实现限制

编译器当前限制表达式嵌套深度及表达式节点数各为 128，块嵌套深度为 64，循环嵌套 64；超出时报告错误。这些是早期实现的资源限制，不是最终语言能力承诺。移动/所有权跟踪覆盖所有拥有型值：string、vec 与结构体变量共用同一套 moved 集合（编译器以 MoveKind::{Var, Field, StrVecElement} 记录），结构体字段与 vec 元素按设计不能被拆出、只能作为借用使用（具体编译期/运行时边界见上文）。比较不可链接；字符串不可变（无原地修改）；这些限制将在后续版本按规范逐步放开。
