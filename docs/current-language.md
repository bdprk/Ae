# AE 当前原型语义（未稳定）

本文只描述已经实现的子集，不代表未来语言最终设计。

## 词法与结构

源文件采用 UTF-8。标识符由 ASCII 字母或下划线开头，后续可包含数字；空白分隔词元，`//` 注释延伸至行尾。程序有且仅有一个 `fn main() { ... }`，也可定义返回整数的函数。语句以分号结束。

## 值与计算

标量值为有符号 64 位整数；局部变量也可声明为固定长度的整数数组。整数字面量目前仅支持 0 至 9223372036854775807；可用减法计算负数，包括最小值。支持括号和 `+ - * /`，乘除高于加减，同优先级左结合，操作数从左到右计算。除法向零截断。溢出及除零使程序非零退出并在标准错误输出运算符的行列位置；两种构建模式不得关闭这些检查。

`let x = expression;` 声明不可变变量；`var x = expression;` 声明可变变量。声明前不能使用变量，不能重复声明；`x = expression;` 仅允许赋值给已有可变变量。花括号引入词法作用域，内层可读写符合可变性规则的外层变量；内层变量离开块后不可见，不能遮蔽当前可见的名称。`print(expression);` 以十进制和换行写入标准输出；输出错误使程序非零退出。

本子集不提供通用所有权系统、可变借用、并发或对整个语言实现的安全保证。语法与语义可能改变。

## 控制流程

`if a < b { ... } else { ... }` 和 `while a < b { ... }` 的条件必须是两个整数表达式之间的比较。支持 `==`、`!=`、`<`、`<=`、`>`、`>=`；条件左右依次计算。`else` 可省略；每次循环重新计算条件。比较目前不是独立的布尔值，暂不支持条件链、break 或 continue。

## 当前实现限制

编译器当前限制表达式嵌套深度及表达式节点数各为 128，块嵌套深度为 64；超出时报告错误。这些是早期实现的资源限制，不是最终语言能力承诺。

## 固定长度数组

`let a = [1, 2];` 声明不可变数组，`var a = [1, 2];` 声明可变数组。数组元素是整数表达式，自左向右求值；数组长度为 1 至 4096，当前只允许声明时使用数组字面量，不支持数组整体赋值、按值传参、返回或嵌套数组。`a[i]` 读取，`a[i] = value;` 需要可变数组。下标须为整数，负数或大于等于长度时程序报告下标位置并以非零状态退出；写入先计算并检查下标，再计算右侧。优化构建保持相同检查。

## 函数

`fn add(a: i64, b: i64) -> i64 { return a + b; }` 定义整数函数，参数不可变且按值传递，最多 64 个；实参从左到右求值。函数可以在调用点之前或之后定义，支持自递归和相互递归。所有路径必须明确返回整数；编译器目前保守地只认可直接 `return` 或 `if`/`else` 两个分支均返回。`main` 不接受参数或 `return`。递归深度受系统栈限制。

## 只读数组参数

函数参数可写为 `a: &[i64; 3]`，调用时用 `f(&values)` 显式传入长度匹配的局部数组或只读数组参数。借用只在调用期间存在，可转借给其他函数；被调用函数不能写入、保存或返回借用。它是一种受限的只读参数，不是完整的借用检查或所有权系统。下标仍执行边界检查。
