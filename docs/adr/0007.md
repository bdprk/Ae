# ADR-7: Compiler Worker Threads Use Large Stacks

- Background: Recursive descent parsing and deep AST deallocation rely on recursion; the default main thread stack size on Windows is relatively small.
- Decision: The compilation entry point offloads work to a dedicated thread with a 256MB stack; the syntax layer still explicitly limits nesting (expressions: 128, blocks: 64, loops: 64).
- Rationale: A stack overflow results in a crash rather than a diagnostic; dual protection ensures that "valid but deep" inputs yield explicit errors instead of crashing.
- Consequences: Increased memory ceiling; limit values are early resource constraints that will be adjusted as needed and documented in the future.
