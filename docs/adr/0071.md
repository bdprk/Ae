# ADR-71：抽出词法 crate

- 状态：已实现（Windows 验证；Linux 待验证）
- 日期：2026-11-12
- 关联里程碑：M0.3–M0.4

## 背景与决定

在 ADR-70 的过渡 workspace 中，将词法器与其词元类型机械迁入 `ae-syntax`，供现有解析器和测试辅助使用。词法规则、词元位置和诊断文本保持原样。该 crate 暂时只实现词法，不代表计划中的解析器、AST、格式化器和错误恢复已经迁入或完成。

现有位置和诊断字符串辅助函数暂随词法器迁移；它们尚不是统一的 `Span`/`Diagnostic`，后续 M0.4 仍需建立有结构的源位置和诊断模型。`ae-compiler` 继续作为过渡 crate，避免把单遍解析/检查误当作已实现 HIR。

## 验证

Windows 上 `cargo test --workspace` 通过；44 个示例文件的 `emit-c` 退出码、标准输出与标准错误均与拆分前记录的 SHA-256 一致（其中两个模块文件作为入口被拒绝）。Linux 验证待做。

迁移时另修复独立缺陷：导入头格式错误时，原实现用空源文件和非零偏移计算位置而崩溃；现在使用实际源文件，并避免重复文件名前缀。UI 快照覆盖非 ASCII 注释后的非法路径与缺少分号。
