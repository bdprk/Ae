# ADR-57: Moving Map State Bits Out of Slots, Reducing Slot Size from 32 to 24 Bytes

- Background: ADR-56 traded "table doubling" for map load times of 1.17x, with the trade-offs documented in the ADR—approximately 64 bytes of slot overhead per element, a peak load of 2.44 -> 3.43 MB, and leaving a "24-byte slot + separate state array" as the next step. This step implements that.
