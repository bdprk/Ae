# ADR-6: Built-in Functions Occupy Reserved Names

- Background: Built-in semantics such as `len` must be globally consistent; local shadowing is not permitted to avoid confusion.
- Decision: `len` is a built-in function, and users cannot redefine it via `fn len`; array length is a compile-time constant, while string length is a runtime byte count (UTF-8).
- Rationale: The rule of counting string length by bytes is simple and predictable; decisions on character-level indexing are deferred to when the string API is designed.
- Consequences: Character-/grapheme-level `len` requires a new name or an explicit API; documentation and tests must be kept in sync as the list of built-in functions grows.
