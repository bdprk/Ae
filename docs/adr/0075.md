# ADR-75: Load import graphs without recursive host calls

- Status: implemented (verified on Windows; Linux verification pending)
- Date: 2026-11-12
- Related: M0 correctness and resource robustness; `spec/modules.md`

## Context and decision

The module loader used a Rust call per import level. Deep acyclic graphs could therefore exhaust the host thread's stack even though the language does not impose an import-depth limit. Replace recursive descent with an explicit stack of pending files. Preserve depth-first source order, canonical-path cycle detection, loading completed files only once, and existing error behavior.

The explicit stack still consumes memory proportional to the active import chain and the source and token buffers it retains. This change does not claim unlimited resource use.

## Verification

On Windows, a 700-file import chain checks successfully on a 512 KiB host thread stack and through the CLI. Its dependency listing contains all 700 files in depth-first order. Existing cycle, diamond, visibility, and diagnostic tests pass. All workspace tests pass and 44 example `emit-c` outputs match the recorded baseline. Linux verification remains pending.
