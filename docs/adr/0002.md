# ADR-2: Integers Checked by Default, No Silent Wrapping

- Context: Integer semantics must be clarified prior to implementation (Proposal §4.2).
- Decision: In any build mode, `+ - * / %` and unary `-` will report the location and terminate upon overflow or division by zero; default wrapping is not provided, and explicit wrapping operations are deferred to be introduced later via named functions.
- Rationale: Safety and correctness have the highest priority; consistent behavior between development and release ensures benchmark data remains valid.
- Consequences: Hot loops incur check overhead; future optimizations for "proven to be eliminable" checks may be added, but semantics remain unchanged.
