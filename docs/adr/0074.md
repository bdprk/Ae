# ADR-74: Move the formatter into the syntax crate

- Status: implemented (verified on Windows; Linux verification pending)
- Date: 2026-11-12
- Milestone: M0.3

## Context and decision

The formatter needs lexical validation but does not depend on parsing, type checking, or C generation. Move it from the transitional compiler crate to `ae-syntax`, where it uses the same lexer directly. Re-export the module from `ae-compiler` to preserve the existing driver interface. Its newly public text-formatting API also performs lexical validation, matching the CLI; semantic errors remain acceptable. Parsing and the AST remain in the transitional compiler crate; this move does not complete M0.3.

## Verification

`cargo test --workspace --locked` passes on Windows, including the formatter's lexer-equivalence and idempotence tests, CLI integration tests, and diagnostic snapshots. Linux verification remains pending.
