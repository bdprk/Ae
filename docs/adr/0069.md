# ADR-69：前端按职责拆分为子模块（零行为变化）

- 状态：已实现（单平台：Windows）
- 日期：2026-11-12
- 关联里程碑：M0.3

## 背景

`src/frontend.rs` 约 330 KB / 5,333 行，词法、解析与检查、C 发射、运行时裁剪混在一个文件，难以协作、难以演进到 HIR/MIR。

## 决定

机械搬迁为 `src/frontend/`：

| 文件 | 职责 |
|---|---|
| `mod.rs` | 共享类型（Token/Type/Expr/Statement/定义）、prelude、模块加载与公开 API |
| `lexer.rs` | 词法与位置 |
| `parser.rs` | 解析器 + 单遍语义检查（`impl Parser`） |
| `codegen.rs` | 语句/表达式到 C |
| `c_output.rs` | C 类型映射、运行时裁剪、整程序 C 组装 |

子模块通过 `use super::*` 访问父模块私有项；跨模块调用项提升为 `pub(super)`。不改变任何逻辑。

后续（M0.3 第二步）在引入 HIR 时再拆成 cargo workspace crates；当前不拆 crate，因为 Parser 与类型定义强耦合，直接拆 crate 需要大量 `pub` 暴露而无收益。

## 证据

- `cargo test --release`：36 单元 + 179 集成全部通过（Windows，MinGW GCC 16.2）。
- 全部 44 个 `examples/**/*.ae` 的 `emit-c` 输出在拆分前后逐字节相同（SHA-256 比较）。
- Linux 回填待做。

## 后果

- `parser.rs` 仍约 2,600 行，将在 M1 引入 HIR 时按“解析”与“检查”进一步分离。
