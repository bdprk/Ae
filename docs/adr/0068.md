# ADR-68：M1 验收前的冻结清单

- 状态：已接受
- 日期：2026-11-12
- 关联里程碑：M0.1（`docs/plan.md` §5.3）

## 背景

类型系统泛型化（M1）会重写容器、结果类型与内建的实现；在此之前继续投入这些区域的工作大部分会被丢弃。

## 决定

在 M1 验收前冻结：

1. 新增编译器内建函数（只允许修复缺陷）。
2. 新增按元素类型手写的容器家族。
3. 新增预置结果枚举。
4. 运行时微优化（装载因子、缓冲区、哈希调优等），除非修复正确性或安全问题。

允许且优先：前端重构（M0）、诊断、测试基础设施、规范编写、HIR/类型推断/方法语法/trait/闭包（M1）。

## 后果

- 现有 ADR-44~66 的实现保留；M1.10/1.11 以泛型标准库重写后，旧名保留一个版本作弃用别名，再删除。
- 冻结解除条件：M1 验收（`docs/plan.md` §6 M1.13–1.14）。
