# ADR-68: Freeze Checklist Prior to M1 Acceptance

- Status: Accepted
- Date: 2026-11-12
- Associated Milestone: M0.1 (`docs/plan.md` §5.3)

## Background

The generification of the type system (M1) will rewrite containers, result types, and built-in implementations. Continuing to invest in work on these areas prior to this will largely result in throwaway code.

## Decision

Freeze the following prior to M1 acceptance:

1. Addition of new compiler intrinsics (bug fixes only).
2. Addition of new element-type-specific handwritten container families.
3. Addition of pre-allocated result enums.
4. Runtime micro-optimizations (load factor, buffer tuning, hashing tuning, etc.), unless fixing correctness or safety issues.

Allowed and prioritized: Frontend refactoring (M0), diagnostics, test infrastructure, specification writing, HIR/type inference/method syntax/traits/closures (M1).

## Consequences

- Implementations from existing ADR-44 through ADR-66 are retained; once rewritten using the generic standard library in M1.10/1.11, the old names will be kept as deprecated aliases for one version before removal.
- Conditions for lifting the freeze: M1 acceptance (`docs/plan.md` §6 M1.13–1.14).
