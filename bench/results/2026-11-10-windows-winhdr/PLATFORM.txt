Boundaries (do not overstate)
  - Programs reaching the file, directory, clock, environment, cwd or child
    process layer still include <windows.h> and still pay for parsing it.
  - No Win32 declarations were hand-written; W6 from the plan document is NOT
    implemented and no ABI assumption was introduced.
  - No new cache kind, no resident process, no safety check was disabled.
  - A missing marker would fail at C compile time (explicit), never silently
    change runtime behaviour; an extra marker only costs one header parse.
  - timings.json is run 2; timings-runs.json holds all three raw runs.
